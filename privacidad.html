PRIVACIDAD

Privacidad

Cómo tratamos la información relacionada con el uso de Travel & More.

Sobre esta web

Travel & More es una web personal de contenido editorial. No tiene formularios de contacto, cuentas de usuario, newsletter ni solicita al visitante que facilite datos personales directamente.

Responsable

El responsable de esta web es el titular de Travel & More.

Para cualquier cuestión relacionada con privacidad o protección de datos puedes contactar en victorguzman.data.pro@gmail.com.

Google Analytics

Utilizamos Google Analytics 4 únicamente con fines estadísticos, para entender de forma agregada cómo se utiliza la web y poder mejorar sus contenidos.

Google Analytics solo se carga si el usuario lo acepta expresamente mediante el panel de privacidad de Travel & More. Si se rechaza, Analytics no se carga.

La información tratada puede incluir datos técnicos del navegador y del dispositivo, páginas visitadas, duración y características de la sesión y una localización geográfica aproximada.

No utilizamos Google Analytics para identificar personalmente a los visitantes ni enviamos a Analytics nombres, direcciones de correo electrónico u otros datos identificativos introducidos por el usuario.

En nuestra configuración de Analytics están desactivadas las señales de Google y la personalización publicitaria.

Base jurídica

La base para utilizar Google Analytics es el consentimiento del usuario. Puedes aceptar, rechazar o cambiar posteriormente tu elección desde el botón Privacidad disponible en la web.

Alojamiento

Travel & More está alojada mediante GitHub Pages. Como proveedor de alojamiento, GitHub puede tratar determinados datos técnicos necesarios para prestar, proteger y mantener su servicio, de acuerdo con su propia política de privacidad.

Conservación

Los datos tratados por Google Analytics se conservan de acuerdo con la configuración de la propiedad de Analytics y con las políticas de conservación de Google.

Destinatarios

Para el servicio de analítica utilizamos Google Analytics, prestado por Google. Para el alojamiento de la web utilizamos GitHub Pages, prestado por GitHub.

Tus derechos

Puedes retirar en cualquier momento el consentimiento dado a Google Analytics desde el botón Privacidad.

También puedes ejercer los derechos que te reconoce la normativa de protección de datos contactando con el responsable a través del correo indicado anteriormente.

Si consideras que el tratamiento de tus datos no se ajusta a la normativa, puedes presentar una reclamación ante la Agencia Española de Protección de Datos.
